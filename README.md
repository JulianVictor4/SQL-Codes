# SQL Practice & Learning Journey

Welcome to my SQL repository! This space serves as a dedicated archive of my daily practice, exercises, and query solutions while following the **SQL with Barra** learning path.

## 📌 Repository Structure & Progress

The scripts in this repository follow a sequential layout based on module topics:

- **Fundamentals:** Database creation, table schemas, data types, and CRUD operations (`INSERT`, `UPDATE`, `DELETE`).
- **Data Filtering & Retrieval:** Basic to advanced filtering using `WHERE`, `LIKE`, `IN`, `BETWEEN`, and sorting with `ORDER BY`.
- **Aggregations:** Grouping and summarizing data using `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`.
- **Joins & Multi-Table Queries:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL OUTER JOIN`.
- **Advanced Querying:** Subqueries, Common Table Expressions (CTEs), and Window Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`).

## 🛠️ Tech Stack & Tools

- **Learning Resource:** SQL with Barra
- **RDBMS:** Microsoft SQL Server (T-SQL)
- **Environment:** SQL Server Management Studio (SSMS)
- **Version Control:** Git & GitHub

## 🎯 Objectives

- Build strong query writing muscle memory through daily hands-on practice.
- Maintain a clean, structured code archive for easy reference.
- Solve real-world data retrieval scenarios efficiently.
